# Sequence Diagram

This document helps render sequence templates into visual diagrams.

Read the main sequence rules and registry at [docs/architecture/sequence-pattern.md](../../architecture/sequence-pattern.md).

&nbsp;

## Usage

1. Copy sequence text from the template you want to use.
2. Open https://sequencediagram.org/.
3. Paste the sequence text.
4. Enable Presentation Mode when needed.
