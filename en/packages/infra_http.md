# infra_http

Infrastructure package implementing `ApiClient` using `http` package.

&nbsp;

## Purpose

This package provides a lightweight, simple HTTP client implementation.

&nbsp;

## Implements

- `ApiClient`

&nbsp;

## Dependencies

- app_core
- http

&nbsp;

## Responsibilities

- REST request
- SSE stream
- request timeout
- response mapping

&nbsp;

## Notes

Does not provide interceptors or advanced features like Dio.

Suitable for simpler projects.
