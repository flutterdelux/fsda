# infra_flutter_secure_storage

Infrastructure package implementing `SecureLocalStorage`.

&nbsp;

## Purpose

Store sensitive data using `flutter_secure_storage`.

&nbsp;

## Implements

- `SecureLocalStorage`

&nbsp;

## Dependencies

- app_core
- flutter_secure_storage

&nbsp;

## Responsibilities

- read
- write
- remove
- contains
- clear

&nbsp;

## Typical Usage

- access token
- refresh token
- private key
- credential
