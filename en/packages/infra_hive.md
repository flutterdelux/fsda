# infra_hive

Infrastructure package implementing `LocalStorage` using Hive.

&nbsp;

## Purpose

LocalStorage alternative with high performance and better object support than SharedPreferences.

&nbsp;

## Implements

- `LocalStorage`

&nbsp;

## Dependencies

- app_core
- hive

&nbsp;

## Responsibilities

- read
- write
- delete
- clear

&nbsp;

## Notes

Current contract support is limited to primitive values in `LocalStorage`.
