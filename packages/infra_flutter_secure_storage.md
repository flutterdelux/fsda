# infra_flutter_secure_storage

Infrastructure package yang mengimplementasikan `SecureLocalStorage`.

&nbsp;

## Purpose

Menyimpan data sensitif menggunakan `flutter_secure_storage`.

&nbsp;

- SecureLocalStorage

&nbsp;

## Dependencies

- app_core
- flutter_secure_storage

&nbsp;

- write

- clear
